## 1. Resource & Knowledge Management
* **Internal First:** Use internal knowledge for standard syntax/logic.
* **Context Verification:** If using a niche library or unstable API (e.g., Next.js App Router), **verify** documentation via Search before coding.
* **Search Restriction:** Use GitHub Search or Context7 only for:
    * New library research.
    * Debugging obscure error codes.
    * Explicit user requests.
