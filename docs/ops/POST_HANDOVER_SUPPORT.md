# POST_HANDOVER_SUPPORT

## 1) Support Window

- Duration: 30 days after handover sign-off
- Scope: Production bug fixes and operational support
- Exclusions: New feature development, architecture redesign

## 2) Response Targets

| Severity | Response Target | Resolution Target |
| :-- | :-- | :-- |
| P1 | ≤ 1 hour | Same day |
| P2 | ≤ 4 hours | ≤ 24 hours |
| P3 | ≤ 1 business day | Planned patch |
| P4 | Next cycle | Backlog |

## 3) Communication Cadence

- Week 1: Daily check-ins
- Week 2: Every 2–3 days
- Week 3–4: Weekly review

## 4) End-of-Support Deliverables

- Incident summary report
- Open known-issues list
- Recommended next maintenance plan
