# CHANGE_REQUEST_LOG

## 1) Purpose

Separate maintenance fixes from new feature requests and avoid scope creep during handover.

## 3) Acceptance Rules

- Maintenance phase prioritizes fixes over enhancements.
- Enhancement requests require separate approval and planning.
- High-risk requests must include rollback strategy.
